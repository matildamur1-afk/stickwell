# Сайт Stickwell / «На полях»

Статичный сайт для GitHub Pages: сборщик и сервер не нужны.

| Файл | Что это |
| --- | --- |
| `index.html` | Лендинг на английском |
| `ru.html` | Лендинг на русском |
| `privacy.html` | Политика конфиденциальности (EN + RU) |
| `assets/config.js` | Ссылка на магазин, почта, GitHub Issues — всё, что нужно дописать после публикации |
| `assets/` | Стили, шрифты, видео, скриншоты, картинка для соцсетей |
| `.nojekyll` | Говорит GitHub Pages отдавать файлы как есть |

Шрифты лежат на самом сайте, без Google Fonts. Поэтому сайт, как и расширение, не делает запросов к сторонним сервисам.

## Как опубликовать (≈10 минут)

1. Зарегистрируйтесь на github.com, если аккаунта ещё нет. Имя аккаунта станет частью адреса сайта.
2. Создайте репозиторий **stickwell**: New repository → Public → Create.
3. Загрузите в него содержимое этой папки: Add file → Upload files → перетащите все файлы и папку `assets` → Commit changes.
   - Файл `.nojekyll` скрытый. Если он не загрузился, создайте его вручную: Add file → Create new file → имя `.nojekyll`, содержимое пустое.
4. Включите Pages: Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
5. Через 1–2 минуты сайт откроется по адресу `https://<аккаунт>.github.io/stickwell/`. Политика конфиденциальности будет по адресу `https://<аккаунт>.github.io/stickwell/privacy.html`.

## Что дописать потом

Дописывается всё в `assets/config.js`, страницы трогать не нужно:

- `issues` — `https://github.com/<аккаунт>/stickwell/issues`. Можно сразу после шага 2. Кнопка «Сообщить об ошибке» появится сама.
- `email` — почта проекта. Появится кнопка «Написать нам», а надпись «Контакты скоро появятся» пропадёт. Почту нужно вписать и в `privacy.html` — там две красные заглушки.
- `store` — ссылка на расширение в Chrome Web Store после публикации. Кнопка «Скоро в Chrome Web Store» станет кнопкой «Установить».

## Проверка после публикации

- Открыть обе страницы и политику без входа в GitHub — должны открываться без ошибки 404.
- Проверить, что видео в начале страницы запускается само.
- Вставить ссылку на сайт в Telegram или Slack — должна появиться карточка с картинкой.
